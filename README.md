# Lernreise

Lern-App für Kinder von 7 bis 11 mit Mungg, dem Murmeltier: die Schweiz (26 Kantone, Wappen, Hauptorte, Karte), Uhr und Kalender,
und vier Sprachen (Französisch, Englisch, Italienisch, Spanisch). Jedes Kind hat sein eigenes Profil, Sticker-Album und Sammelbuch.
Fürs iPad, iPhone und den PC; läuft auch ohne Internet (Safari → Teilen → «Zum Home-Bildschirm»).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Lernreise` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
Bilder: OpenAI. Stimmen: ElevenLabs. Wappen: Wikimedia Commons (gemeinfrei). Karte: BFS/swisstopo, aufbereitet von swiss-maps
(Interactive Things, BSD-3). Schrift «Nunito» unter der SIL Open Font License (`fonts/OFL.txt`).
